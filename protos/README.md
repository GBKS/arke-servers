# Protos

`bark_server.proto` and `core.proto` are copied unmodified from
[Bark](https://gitlab.com/ark-bitcoin/bark) (`server-rpc/protos/`) at commit
`84d56f2874da0be981711ab9d2a0e3a073be55d4`, licensed under MIT
(Copyright (c) 2026 The Bark Contributors).

`health.proto` is the subset of the standard gRPC health checking protocol
that the probe uses.

To update, copy the files from a newer Bark checkout and note the commit here.
